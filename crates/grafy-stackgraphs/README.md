# grafy-stackgraphs

Stack-graphs-based cross-file name resolution for [Grafy](https://github.com/daneuchar/Grafy).

**Status:** pre-M0 placeholder (v0.1.0). Real engine lands in M2 (plan §4).

## What it will do

Binding-precise cross-file reference resolution for Python, TypeScript, and Java, verifiable against per-language SCIP indexers (F1 ≥ 0.85 target).

## Strategy

M2 week 1 subprocess-validates against upstream [github/stack-graphs](https://github.com/github/stack-graphs) (archived September 2025) before deciding fork-vs-vendor.
